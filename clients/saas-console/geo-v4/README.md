# 玄钧AI新 GEO 客户侧定稿 V4

这是获准公开交接的静态交互原型，不是生产实现。仅包含客户侧；不含管理端、凭据、账号配置或客户资料。青禾知识库、示例网址与数值全部是构造的演示数据。

## 文件与运行

- `index.html`：客户壳层，白色顶部与浅色侧栏。
- `styles.css`：基础布局与响应式组件。
- `ecosystem.css`：SaaS 生态视觉覆盖，最后加载。
- `app.js`：全部浏览器内交互与固定演示数据。
- `SHA256SUMS`：上述文件和本说明的 SHA-256。

四个实现文件逐字节保持定稿，不改样式、功能、文案或业务数据。将目录通过任意静态 HTTP 服务打开即可；无需安装依赖、服务端、外部账号或密钥。保留三个资源相对于入口的路径关系。

## 保留的客户功能

四个主导航：总览、诊断、优化、效果。品牌设置只管理当前品牌，持续优化由效果承接；没有后台入口或角色切换。

完整流程：设置当前品牌 → 查看问题原因、回答证据、相关页面与初始数据 → 接受优化建议 → 补充资料 → 系统建议 → 明确确认当前版本 → 页面更新结果核对 → 页面生效检查 → 同范围前后对照 → 下一轮建议。

评论不等于批准；批准绑定当前版本。更新结果不确定时先核对，不重复更新；当前动作只推进浏览器中的演示进度，不改变历史效果数字。

## 数据与边界

固定对照期为 10.01–10.07 和 10.22–10.28，各 7 天，每期 240 条有效回答。官网引用 48→78（20%→32.5%），品牌提及 96→108（40%→45%）；平台和品牌词分组可筛选且合计一致。未完成检查不算未提及，独立列出。改善、持平、下降与样本不足分别呈现。实际访问和客户询盘尚未关联，不推算转化或收入。

代码无外部请求、秘密输入或真实发布能力，不收费、不创建真实任务、不修改生产系统。生产集成应复用现有 SaaS 的账户、品牌权限、模块权益、审核、任务和用量能力；本交接没有实现这些后端能力。客户与后台页面分离不代表真实授权隔离已经完成。
