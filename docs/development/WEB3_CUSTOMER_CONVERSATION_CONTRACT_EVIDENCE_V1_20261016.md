# 玄钧云汇Web3.0客户全生命周期会话、选择与合同证据 V1

状态：OWNER_CONFIRMED_DESIGN / IMPLEMENTATION_PENDING / PRODUCTION_HOLD。Web3.0是玄钧生态的证据记账层：从客户第一次联系开始，对AI网站聊天、用户Telegram、用户飞书、客服人工消息、需求/报价/材料/授权/签约/履约/验收/退款争议记录形成可核验事件链。复用统一Customer/Project/CRM及已有聊天证据、Finance/Contract/Task canonical账本，不另建客户身份或合同账本。不同项目终端用户按项目作用域隔离。

## 记录内容
会话事件含event_id、customer_id或项目project_user_id、tenant_id、project_id、channel及对应应用身份、session_id、发送者经验证身份、服务器时间、消息原文及附件受控引用、语言、授权的处理目的、前序版本引用、消息hash、prev_event_hash、审计来源与更正/撤回事件；保留消息进出方向、送达/失败/重试/UNKNOWN状态。聊天不自动视作客户同意合同条款或单独授权；明确区分咨询、草稿、选择、送审、最终签约、付款、验收。
每次客户点击购买选项和资源方式（客户自带、自购、玄钧代购、玄钧提供）、价格范围、正式双币价目版本、服务器配置、域名、备案、证书、平台认证、API/SecretRef类型、授权边界、付款方式及预算，记录old_value/new_value、页面/披露版本、actor、可信时间、幂等ID、结果，并追加而不覆写。
合同绑定签约前客户可见的冻结附件：需求/交付边界、所有资源与价格（首购、续费、API用量、税费等）、客户已有与待提交材料、每个第三方认证和凭据的安全获取教程、最高必要授权范围、变更/延期/退款责任、IP与模块复用、运维/退出与验收。最终合同和附件内容SHA256与客户主动确认的可靠签约证据一致；只要重大条款变更，就重新确认，不能以浏览或勾选所有项替代有效签署。

## Web3.0与隐私
客户聊天原文、上传资料、合同原文、身份证、密钥、业务秘密均保存在受控的项目私有存储/证据库，并依各自保留期和访问角色管理；链上或对公众可读取的Web3.0层只记录批次承诺、加盐/防关联设计后的摘要、时间锚和必要的证明，不存任何原文、直接标识或可反查客户的数据。即使纯SHA也可能重新识别低熵信息，因此不得将单条可关联客户哈希直接公开上链。私有证据账本append-only并支持依法限制、纠错事件、受控删除/匿名化；公开承诺不保证绝对不可撤回或自动具备司法证明力。跨境与第三方AI处理另按客户合法告知、角色和安全评估执行。
外部飞书/Telegram用户和网站AI绑定真实Customer ID后才能合并同一客户档案；未验证身份的咨询单独记录未认领会话并按规定处理，不能只凭昵称或转发链接绑定既有客户。

## 签约及收款强制门禁
未完成完整资源成本/方案选择、最高必要授权范围披露、证照及第三方认证与密钥清单、客户确认及精确合同附件冻结时，CONTRACT_SIGN、PAYMENT_CREATE、PROJECT_START、PROCUREMENT均HOLD。草稿可分批修改，前序事件追加保留；客户应当能够在自己的项目中心下载完整聊天与选择历史的依法可导出部分、报价附件、合同及确认回执。不得以聊天记录本身代替法律要求的有权签署。

## 验收
A从网页AI转飞书再Telegram，真实绑定后同一Customer ID保留完整会话顺序并按项目权限可查；未经授权无法看到其他项目或别人的聊天。每项资源的多次选购变更及旧价、新价、责任/认证变化均可追溯，合同冻结与客户所确认版本相等。聊天中的口头承诺不能取代合同，重要变化需重新确认。测试重放、并发、丢消息/UNKNOWN、Webhook重复、传输失败、断网重启、事件链篡改、数据删除/导出与隐私泄漏。公开链上不可查询原文、账号、密钥或可识别用户；实际链上锚定服务未验收则CHAIN_ANCHOR_NOT_CONNECTED，不得伪称链上已存证。
