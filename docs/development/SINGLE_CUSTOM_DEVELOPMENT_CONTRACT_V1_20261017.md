# 玄钧云汇定制开发：唯一电子合同生成规则 V1

Owner纠正此前“主合同加五份客户附件”的过度设计。**客户最终仅需阅读、确认、签署并下载一份完整的定制开发电子合同**。客户选购界面所选项目、报价、资源、权限与准备材料实时汇入该合同的对应章节。内部可保持结构化数据和版本化证据记录，但不能因此要求客户签署五份独立合同或重复确认相同事项。

## 一份电子合同的章节

1. 签约双方、项目与范围：项目名称、功能与页面、业务架构、交付内容及验收标准、明确不包含部分。
2. 客户最终选购结果：客户已有/自购/玄钧代购/玄钧提供，域名、服务器、证书、备案、第三方API、软件模块与归属。
3. 完整费用及付款：每项第三方本金、代购费、部署费、开发费、维护费、税费和持续费用；人民币/美元双币明细与实际结算币种；首次收开发费50%加已确认的第三方代购首期费用和约定服务费；最终验收合格后收开发费剩余50%，不垫付第三方采购。
4. 客户准备事项：必须办理的平台认证、资质、证照、API权限和凭据类型、官方获取教程、责任方与缺失影响；秘密值仅走私有OAuth/SecretRef，不写入合同。
5. 授权范围：整个生命周期内允许玄钧代办和操作的资源、最大必要权限、预算/时效及撤销、运维续费和退出安排。
6. 开发、验收与变更：开发里程碑、客户在功能页面提出整改的权限、原约定免费修复、超范围变更另行确认、历史证据可按功能ID查证。
7. 退款、争议、知识产权、隐私与Web3证据：按实际履行、可退第三方支出及法律处理；客户聊天、选购和历史确认保存受控私有记录，公开链不放原文；明确通用模块复用/IP及保密。

## 自动生成与确认

后台保留一个结构化contract_snapshot，字段包含project_id、verified_customer_id、requirements_version、feature/page清单、resource_selection、quote/pricebook_version、authorization_scope、materials_requirements、payment_schedule、evidence_manifest、contract_document_hash、confirmed_identity/time和legally_valid_signature。客户每次选购动态更新合同预览；点击“查看完整合同”看到的是**一份**连贯文件，最终仅签署这一个冻结版本。内部独立数据表/哈希/聊天记录是证据，不是另外几份要客户签字的合同。支持下载一份PDF。

售前全部知情和一键确认是不同事情：必须允许客户展开查阅各项重大条款、主动确认，不能靠预勾选或模糊授权。付款、签署和开发启动依旧要在服务端验证全部必需项、有效身份及准确版本；重大变更须形成与原合同关联的**一次变更确认**，不重签数份相同材料。
