# 玄钧云汇客户登录、项目资料分批提交及私有协议渠道

状态 SOURCE_ONLY，生产登录/文件上传/渠道绑定/审核/存储 NOT_DEPLOYED。不得用演示系统采集真实证件、合同或密钥。

- 公共官网与客户中心由国内服务器承载；英国仅控制开发、审核及受控发布。ChatGPT Library 的「私有协议库」不是服务器容器，也不具有已验证的项目级访问控制；正式存储须在经授权的国内受控私有存储/对象存储内配置项目级RBAC、加密、审计及备份。
- 复用已有Tenant、Customer、Project、CRM、认证与SecretRef，绝不重复创建账号数据库或财务/合同权威账本。真实登录状态为WAITING_AUTH_INTEGRATION，不能假定现在可登录。
- 用户注册与登录后，须由可信服务端核实签约主体/原合同客户、项目授权以及租户/项目身份。合同/订单号或邀请链接本身不能授予提交权。企业组织可由经验证的项目所有者明确授权成员，权限可撤销。
- 按项目自动生成客户材料清单，资料可逐项保存草稿、提交、驳回补正、重新提交；状态为 NOT_STARTED/PARTIAL/SUBMITTED/NEEDS_CORRECTION/ACCEPTED；每次版本及处理者入审计，不覆盖已确认签署原件。
- 每项明确说明：用途、需要的账号资质、取得方式、官方平台入口、最小权限、有效期、审核方、是否敏感、验证办法及缺少时的替代路径。演示已提供公司身份、DNS域名、微信商户及分账、微信小程序、抖音OAuth、X开发者授权等需求模板。每个项目仅显示自己真实需要的条目，不要求客户无谓购买或认证。
- API密钥、微信支付私钥、AppSecret和OAuth令牌禁止通过普通附件、Telegram、飞书或网页聊天提交；使用OAuth或专属加密Secret Portal直接传入SecretRef。普通营业执照/合同经隔离、病毒扫描及访问控制后上传，禁公网匿名访问。
- 客户沟通：网页客户中心为项目和身份权威入口。Telegram/飞书通过受控短期一次性挑战绑定，只接任务状态及脱敏提醒；未经真实Webhook/Provider验收显示PENDING而非CONNECTED。
- 额外必须考虑：材料到期提醒、账号找回、代表授权撤销、交接责任人、恶意文件检测、上传上限、审阅冲突、企业变更、数据保留/导出/删除申请、授权撤销、合同版本确认、真实浏览器负向越权测试。
- 这份增量只提供无副作用业务校验和规范，不改变既有PR122/PR17/P2/站点/Finance生产门禁。正式上线需Work/原网站Owner核实部署通道、审查与安全测试后接入。
