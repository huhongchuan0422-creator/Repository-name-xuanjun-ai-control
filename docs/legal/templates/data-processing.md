# 个人信息与客户数据委托处理附件

版本：2026-10-15-draft.1
状态：DRAFT_NOT_FOR_SIGNATURE

本文件为待审核草案，不是已经生效的交易条件。签约封面：【运营主体及登记信息】【业务参数与适用地区确认表】。签约前须填写运营主体全称、统一社会信用代码/注册号、地址、有效联系方式、适用业务、费用、期限和争议解决条款；空缺、未审核或与真实产品不一致时，不得进入签署或收款流程。适用强制性法律优先，订单和专项附件不得减损消费者法定权利。重大利害条款须醒目提示并按请求解释；不得预勾选、以浏览代替同意或追溯适用新版本。

一、角色。委托方【主体】、受托方【主体】；按真实目的决定者区分委托处理、共同处理和独立提供，不能全部假写为受托。附处理活动清单：目的、期限、字段/人员类别、规模、操作、环境/地区、法律依据、敏感信息和授权范围。
二、指令与限制。受托方仅按合法书面指令处理，不自用、不营销、不训练通用模型、不未经批准合并客户数据；发现指令违法或不清楚时暂停对应处理并通知。客户内容和个人信息不因合同变成平台财产。
三、安全。最小权限、租户隔离、加密、密钥管理、日志、备份、恢复、漏洞与访问审计按附件标准执行；开发测试用合成/充分脱敏数据。列明安全事件通知时限【填写】、所需证据和处置职责，不夸大绝对安全。
四、分包与出境。分受托方名单、作用、地区与变更通知/反对机制逐项约定；未经必要同意/授权不转委托。跨境传输或远程境外访问先完成适用告知、单独同意、影响评估及所需合法机制，不能只凭本附件放行。
五、协助与终止。协助用户权利、监管、风险评估及合理审计；终止后按指令返还/删除并出具可验证记录，不留超范围副本。法定留存例外写明范围和期限。双方按实际过错/角色担责，不把受托方义务全部推给用户。
