# 软件与AI定制开发合同附件：客户交互选择、沟通记录与Web3.0存证条款（草案）

版本：2026-10-16-draft.1。状态：DRAFT_NOT_FOR_SIGNATURE。未经主体、隐私及独立法律审核，不开放签署或真实收款。本附件拟与原《软件与AI定制开发主合同》《定制项目需求范围、报价与验收任务书》绑定同一冻结版本，正式合同时作为不可分割附件，而非另签一套合同。

一、客户在订购前通过官方受控项目中心，逐项选定软件模块、域名/备案、证书、服务器与数据库、支付渠道、AI模型、第三方接口、采购或代购方式、授权范围、运维和续费等内容。页面显示价格范围与准确报价的区别，最后合同以客户明确确认的报价版本和附件快照为准，含一次性、周期、按量及第三方费用，双币报价并写明实际支付币种。不得以客户的浏览或未勾选行为推定选择、接受额外费用或授权。

二、平台必须事先一次披露项目交付所需全部可预见资质、认证主体、证照、API权限、密钥类型、获取教程、最高必要授权操作及失效/续费后果。客户可分批准备材料，但未充分知情/未确认范围时，不签约、不收款、不启动正式开发。对真正不可确定的第三方价格或审批，明确风险与合同条件，重大不确定性不得当成已具备。

三、留证范围包括网站AI、用户飞书和Telegram的客服沟通、咨询意图、客服承诺、需求版本、客户逐项点击/取消选项、价格变化、认证/授权确认、材料清单、合同及后续变更、测试、验收、投诉和退款沟通。记录可信消息/事件ID、渠道、签约客户与项目、时间戳、版本、事件摘要、操作人身份和送达结果。沟通内容仅在合法处理依据及隐私告知范围内保留，按角色隔离供双方查询、依法导出并核对；有异议的记录以补充更正事件解释，不静默覆盖原记录。

四、Web3.0记录为辅助手段：完整聊天/合同及客户材料保存在受控私有证据库；链上仅可提交隐私设计后的批次证明或必要摘要锚点，不上传原文、身份证、密钥、联系方式及可直接关联用户的标识。双方同意记录版本哈希仅证明对应数据与该摘要的匹配，不当然证明聊天内容真实、对方有签约资格或已经同意合同。不得用“上链不可改”拒绝依法更正、删除或限制处理个人信息。

五、除经双方有效确认的合同/变更单外，AI聊天生成的非正式估算、建议、意向和测试演示不自行构成新的价格承诺或付款授权；但双方不得因此否认真实发生的沟通事实，依法适用的缔约说明、消费者权利与虚假宣传责任不因本条消失。AI遗漏可预见必需条件、错误报价及擅自采购等责任依据事实、合同及法律处理，不能概括全部归责客户。

六、任何影响功能、费用、域名/云资源归属、最高必要授权、第三方续费、备案可行性或交付时间的重大变更，应提供逐项新旧对比、完整费用和风险说明，并取得有权客户对冻结新版本的明确确认。未有效确认的新增收费、采购和受限开发继续HOLD；已经签署的原版本、已付款与对账事实不得被新的选择静默覆盖。

七、正式签署前须确认运营主体、数据处理者、联系方式、适用地域、法定个人信息告知与保留期限、消息第三方处理范围、合同版本及权威签署证据。正式页面不得预勾选重大条款、自动替用户确认或默认将其聊天输入用于模型训练。

合同附件绑定字段：contract_id、customer_id、project_id、sow_version、quote_version、requirements_snapshot_hash、resource_selection_snapshot_hash、authorization_scope_snapshot_hash、conversation_evidence_manifest_hash、privacy_notice_version、acknowledged_by、acknowledged_at、signature_evidence_ref。所有字段由受信服务端确认，不能信任客户端自报。
