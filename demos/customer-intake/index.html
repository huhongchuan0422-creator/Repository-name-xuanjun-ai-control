客户项目 · 资料准备指引

这是不收集数据的静态演示页面。正式注册、登录、合同客户核验和项目私有材料提交尚未接通。请勿在本页面输入身份证件、营业执照、密码、密钥或Token。需要的资料以实际项目清单为准，并非所有项目都需全部认证。

正式接入后：登录 → 验证原签约客户及项目成员资格 → 查看按项目生成的材料清单 → 分批提交 → 审核与补正 → 项目验收。

按合同要求

企业主体及代表授权

准备内容：营业执照、项目联系人及授权代表证明

获取方式：在国家企业信用信息公示系统核验企业信息；由经授权成员通过私有项目通道提交证明，不在公开页面上传证照。

提交方式：经项目授权的私有附件

访问对应官方平台

按域名项目

域名与DNS控制权

准备内容：域名信息及临时TXT记录

获取方式：在域名注册商的DNS管理页面添加站内一次性TXT挑战，验证后按指引移除；不提交域名账户密码。

提交方式：站内限时域名挑战

域名服务商因客户而异，按现有账户选择。

按真实支付项目

微信支付商户及分账能力

准备内容：商户号、分账能力和业务资质

获取方式：通过微信支付商户平台申请商户和所需分账能力；商户号可登记，APIv3密钥/证书私钥只能通过SecretRef。

提交方式：登记公开标识，敏感凭据仅经SecretRef

访问对应官方平台

按微信项目

微信小程序及公众号

准备内容：AppID、已认证应用和服务器域名

获取方式：在微信公众平台注册/认证小程序或公众号，再核对回调域名；AppSecret必须使用受控SecretRef。

提交方式：登记公开标识，敏感凭据仅经SecretRef

访问对应官方平台

按抖音集成

抖音开放平台应用

准备内容：应用审批和所需Scope

获取方式：在抖音开放平台申请应用、核对实际权限，以站内OAuth绑定；不向客服发送Token。

提交方式：通过官方授权流程

访问对应官方平台

按X集成

X开发者应用

准备内容：开发者应用权限、回调及费用预算

获取方式：在X开发者入口核实订阅、接口及预算，再通过OAuth绑定，不能假定现有权限可用。

提交方式：通过官方授权流程

访问对应官方平台

材料审核和替代路径

企业主体及代表授权

用途：签约主体比对及代表授权

最小权限：仅申请项目必要的主体/代表权限；不得索取个人账户密码

有效期：以证照/授权有效期为准；到期需更新

审核方：客户主体审核员

验证方法：核对合同客户与官方主体、代表授权和资料有效期

替代路径：无法取得时暂停该项目签约并申请人工核验，不允许他人代签

获取步骤：在国家企业信用信息公示系统核验企业信息；由经授权成员通过私有项目通道提交证明，不在公开页面上传证照。 → 核对实际权限及费用与合同是否匹配。 → 在私有项目中心查看审核结果；敏感凭据使用OAuth或SecretRef。

域名与DNS控制权

用途：域名及回调所有权确认

最小权限：仅限一次性TXT验证；不交出域名账户

有效期：挑战短有效期，由服务端生成

审核方：项目技术审核员

验证方法：核对指定TXT内容、Host和挑战时效

替代路径：没有域名时可由客户申请或在经批准的托管域名开展隔离演示

获取步骤：在域名注册商的DNS管理页面添加站内一次性TXT挑战，验证后按指引移除；不提交域名账户密码。 → 核对实际权限及费用与合同是否匹配。 → 在私有项目中心查看审核结果；敏感凭据使用OAuth或SecretRef。

微信支付商户及分账能力

用途：支付商户及分账准入

最小权限：只开实际业务所需商户/分账权限；禁止提现权限授予技术方

有效期：按支付平台证书/商户资格有效期核验

审核方：支付合规审核员

验证方法：实际商户后台资格、分账权限与绑定主体一致

替代路径：未获批时仅提供无资金离线演示，不能发起真实付款

获取步骤：通过微信支付商户平台申请商户和所需分账能力；商户号可登记，APIv3密钥/证书私钥只能通过SecretRef。 → 核对实际权限及费用与合同是否匹配。 → 在私有项目中心查看审核结果；敏感凭据使用OAuth或SecretRef。

微信小程序及公众号

用途：小程序与公众号业务接入

最小权限：按实际功能申请所需接口Scope和域名白名单

有效期：以应用认证及密钥轮换周期为准

审核方：渠道集成审核员

验证方法：核对已认证应用、AppID及实际回调域名

替代路径：尚未获认证时使用浏览器离线演示，不宣称可在微信内运行

获取步骤：在微信公众平台注册/认证小程序或公众号，再核对回调域名；AppSecret必须使用受控SecretRef。 → 核对实际权限及费用与合同是否匹配。 → 在私有项目中心查看审核结果；敏感凭据使用OAuth或SecretRef。

抖音开放平台应用

用途：抖音应用及实际开放接口

最小权限：只申请明确用到的最小Scope；禁索取平台密码

有效期：OAuth授权有效期取平台返回值

审核方：渠道集成审核员

验证方法：核对应用归属、Scope和真实授权回执

替代路径：接口权限未获批时停用对应集成，只展示离线功能

获取步骤：在抖音开放平台申请应用、核对实际权限，以站内OAuth绑定；不向客服发送Token。 → 核对实际权限及费用与合同是否匹配。 → 在私有项目中心查看审核结果；敏感凭据使用OAuth或SecretRef。

X开发者应用

用途：X应用及所需数据授权

最小权限：使用最小Scope、限额与预算；不得申请无关访问

有效期：依平台Token到期及授权撤销事件

审核方：渠道集成审核员

验证方法：核对账号授权身份、Scope和费用准入

替代路径：费用或权限未确认则不启动付费调用，使用静态演示

获取步骤：在X开发者入口核实订阅、接口及预算，再通过OAuth绑定，不能假定现有权限可用。 → 核对实际权限及费用与合同是否匹配。 → 在私有项目中心查看审核结果；敏感凭据使用OAuth或SecretRef。
