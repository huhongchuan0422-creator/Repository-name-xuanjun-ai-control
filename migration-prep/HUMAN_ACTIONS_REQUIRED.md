# Single consolidated human cooperation node

No plaintext password, API key, secret, token, cookie, private key, or TOTP is
requested. Complete the following only through protected administrator/SecretRef
flows after independent source review and a new Owner Release Gate.

1. **GitHub Runner administration** — privately attest current agent IDs 4/3,
   repository/organization assignment and admission policy; later issue two scoped,
   short-lived removal tokens directly to the approved executor. Do not paste tokens
   into PR, Feishu, files, command history, or logs.
2. **Bounded root read-only evidence** — run only the separately reviewed read-only
   inventory helper for root/yibi/githubrunner crontabs, applicable systemd units and
   complete sudoers/source closure. This is evidence only; do not enlarge Runner root
   grants and do not stop a service.
3. **Gateway-wide triggers** — export the administrator-complete OpenClaw automation/
   cron trigger inventory so every Yibi and Writer launch/import route can be matched
   to one of the 95 records. Caller-scoped output is insufficient.
4. **Independent trust and Authority** — provision an independently managed Ed25519
   public trust anchor, publish its fingerprint through a protected authority record,
   sign the exact candidate manifest, and bind any future request to exact host,
   paths, units, action, candidate hash, expiry and a single-use nonce.
5. **Owner decisions** — approve or change the 24-hour Shadow threshold and later
   canary bounds; approve the exact evidence root and bounded maintenance window.
   These decisions do not themselves authorize deployment or Writer activation.

After the evidence is returned, an independent reviewer must close every remaining
`UNKNOWN`. A separate Owner authorization is still required for Runner exit, Yibi
retirement, credential/IP changes, production DB freeze, Korea installation, live
Binance GET, Shadow/Canary or Writer authority.
