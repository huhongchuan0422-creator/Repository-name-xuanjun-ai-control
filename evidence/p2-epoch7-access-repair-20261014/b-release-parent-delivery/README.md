# Single-attempt parent-directory preparation delivery

This delivery stages the separately identified parent-fix compiler and the three
bound preparation sources, then invokes the reviewed preparation operation once.
The original R7 observation, A review body and evidence kit remain unchanged.

## Exact effects

- Download one hash/length-bound compiler archive and three hash/length-bound
  preparation source files from fixed immutable GitHub URLs. The outer command
  first downloads this hash-bound delivery helper. The preparation wrapper fetches
  the independently validated topology review by the explicit numeric ID.
- Use only the fixed compiler sibling `epoch7-recovery-candidate-r7-parentfix`
  and preparation sibling `epoch7-preparation-candidate-r7-fresh-parent`.
- If absent, exclusively create the compiler's 42 directories and 254 files
  (directories 0700; newly created files finalized 0444), and the preparation's
  one directory plus three 0600 files. If already present, require an exact full
  match; partial, foreign, extra or symlink contents are refused without repair.
- Read the fixed saved observation and original A kit; perform the reviewed fresh
  B authority/input checks including the release parent and 33 unit roots.
- After real review validation and compilation, exclusively publish the existing
  three private plan/seed/review-packet outputs. Recheck sources, both kits and
  collected authorities. Report any partial output metadata if a later step fails.
- No probe, service operation, installation, production resume, recursive repair,
  directory deletion, retry loop or cleanup of a failed staging tree is provided.
  Reads may update access times. The timer parameter describes the future plan;
  this delivery does not start or enable the timer.

The archive staging, download, module loading and first verification share a
60-second budget. Preparation retains its own reviewed 120-second budget. Status
output is bounded to 131072 bytes and 5 seconds. A failed/partial attempt stops.
Existing staged source and original failure evidence are retained.
