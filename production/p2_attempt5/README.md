## 生产适配器增量：native_adapter.py

Registry R1/R2在PR58#6250317194已关闭；该组件及原951/83项的未变限定结论继承。

native_adapter.py新增public_modulus、build_driver、build_host_readback。它不是安装器，不提供fixture模式，不初始化AuthorityStore/注册Grant/生成密钥，也不直接执行安装命令。
public_modulus读取独立固定SHA的PUBLIC KEY PEM，以OpenSSL验证RSA2048–4096、指数65537，DER摘要必须等于配置公钥信任摘要；run不读取Signer私钥。
build_driver复用已审legacy verify_kit、准确私有plan/seed读取、固定UTF8 hydration、原探针回执认证、prepare_host_inputs纯编译和assemble_host_driver实际16阶段工厂。不会调用旧resume_once、Prepare或重新采集探针。原NativeRecovery仍认证独立安装许可、原生controls及containment，未提供跳过接口。
build_host_readback接真实受保护Unix socket，复用原UnixTransport的root内核peer身份及有限帧/超时；每请求新随机nonce，返回独立observer签名、准确操作/payload/Grant/Attempt、最多30秒有效期、Run/Job/InvokeId、backup/checkpoint/log摘要。拒绝缺失/UNKNOWN/漂移/旧nonce/过期/错误签名，不重发不确定请求。此处是可信observer客户端，不能生产或伪造真实观察结果；仓库未证明英国有该协议的原受信observer服务。缺失时仍HOLD，不能部署一个测试服务替代。

entry.py在Registry核验、完整Kit载入后对提供bind_deployment的适配器执行受控装配：adapter本身必须在新Grant绑定Manifest内；同位置native_adapter.py.binding.json必须列入同Manifest并由root/0600固定摘要读取。外部未审路径不能借此成为默认适配器。私有binding包括schema、hostname、principal、issuer、public_key(path/sha256)、receipt_public_key(path/sha256)、receipt_issuer、receipt_socket、legacy_manifest_sha256、approved_plan(path/sha256)、private_seed(path/sha256)、legacy_review_id、legacy_approval_body_sha256。绑定只一次，cfg变化拒绝。私有binding不包含Grant/Manifest自摘要，避免循环哈希；由完整新Manifest及正式Grant绑定其准确字节。没有真实binding文件，公开CI包不能自动变成可安装包。

本轮21项新测试使用真实RSA/OpenSSL、Unix socket、ReceiptProvider、AuthorityStore、IssuerService、Registry和完整原Kit，在隔离Hosted root目录运行。observer进程仅在测试中产生明确SYNTHETIC_ONLY事实，测试Provider不替换生产ReceiptProvider。正式serve正向通过真实Kit/登记/Signer/共享库/消费/独立签名observer/安全对账/已提交结果读取；run正式入口通过绑定及公钥，进入原具体工厂后因缺原始私有plan/seed而拒绝，不创建Attempt。该测试不是run安装成功，也没有英国实机验收。
